Brand Style Guide

Versões oficiais do logo Xperiun. Logotipos (com nome) atendem contextos onde a marca precisa ser identificada por extenso; símbolos (apenas o glifo X) servem como ícone ou aplicação reduzida.

Logotipos

  • Core Logo Light
  • Core Logo Dark
  • Xpurple Logo
  • Golden Logo
  • Base Black Logo
  • Base White Logo
Proibições
  • Recolorir com cores fora da paleta oficial. Use sempre uma das variantes definidas (Core Light/Dark, Xpurple, Golden, Base White ou Base Black).
  • Distorcer proporções (esticar, comprimir ou alterar a relação de aspecto).
  • Rotacionar ou inclinar.
  • Aplicar efeitos decorativos como sombra, brilho, contorno ou gradient não-oficial.
  • Inserir dentro de caixas, recortes ou recipientes que comprometam a área de respiro.
  • Separar em ocasião alguma o tipo "Xperiun" do símbolo Xperiun. O logotipo é, por regra, o tipo somado ao símbolo indissociáveis.
Evitar
  • Aplicar transparência nos logos coloridos (Core, Xpurple, Golden). Para opacidade reduzida, prefira Base White ou Base Black — foram desenhados para suportar esse uso sem perda de identidade.
  • Sobrepor a fundos com ruído visual ou baixo contraste sem aplicar um scrim que garanta legibilidade.
  • Reduzir abaixo do tamanho mínimo legível para o contexto.

Símbolos

  • Símbolo Xperiun
  • Símbolo Xperiun Ícone
Permitido
  • Aplicar o símbolo em qualquer cor da paleta Brand Colors (Primary Core, Primary Purple, Secondary Gold, Light Neutral ou Dark Neutral) sempre que o contexto exigir adaptação cromática.
Evitar
  • Usar cores fora da paleta oficial. Mesmo que a aplicação peça flexibilidade, mantenha-se dentro do sistema cromático da marca.
  • Combinações de cor + fundo com contraste insuficiente que comprometam a legibilidade do símbolo.

Estrutura

class="btn" Classe base. Obrigatória em todo botão. Define forma, cursor, transição e layout flex interno.
data-size="m" Tamanho: define font-size e padding. Valores disponíveis: data-size="xl" data-size="l" data-size="m" data-size="s". Adicione -ico ao final para a versão com ícone.
data-emphasis="subtle" Ênfase: define cor, background e hierarquia visual. Valores: data-emphasis="high" data-emphasis="medium-core" data-emphasis="medium" data-emphasis="neutral" data-emphasis="subtle" data-emphasis="subtle-dark".

Tamanhos

data-size="l" CTA de hero, cards grandes. Padding 16/32px.
data-size="m" Padrão para a maioria dos casos. Padding 12/24px.
data-size="s" Ações em tabelas, cards compactos, toolbars. Padding 8/16px.

Ênfases

  • A enfase comunica hierarquia visual. Nunca use mais de um data-emphasis="high" ou data-emphasis="medium-core" por tela.
  • data-emphasis="high" e data-emphasis="medium-core": CTAs principais com gradiente animado. Reserve para a acao mais importante.
  • data-emphasis="medium", data-emphasis="neutral", data-emphasis="subtle", data-emphasis="subtle-dark": acoes secundarias e terciarias, em ordem decrescente de destaque.
data-emphasis="high" CTA principal. Gradiente sg100-sg500-sg700 (200%, animado no hover). Texto bb. Borda inset 2px sg100.
data-emphasis="medium-core" Identidade de marca. Gradiente pp300-pc500-pc300 (200%, animado). Texto bw. Alternativa ao High em contextos brand.
data-emphasis="medium" Acao primaria em escuro. Gradiente pc100-pc300-pc500. Texto bb no default, bw no hover.
data-emphasis="neutral" Fundo bw solido, texto bb. Hover: fundo bw-75 + borda inset 2px bw. Para superficies escuras.
data-emphasis="subtle" Fundo dn400 + ring-10. Texto bw. Hover: fundo bw-75, texto bb, borda inset 2px bw. O mais usado no DS.
data-emphasis="subtle-dark" Fundo dn700 + ring-10, texto bw-75. Hover: fundo bw-75, texto bb. Para superficies dn800+. 
<button class="btn" data-size="m" data-emphasis="high">Acao principal</button>
<button class="btn" data-size="m" data-emphasis="medium-core">Identidade</button>
<button class="btn" data-size="m" data-emphasis="medium">Primario escuro</button>
<button class="btn" data-size="m" data-emphasis="neutral">Secundario</button>
<button class="btn" data-size="m" data-emphasis="subtle">Terciario</button>
<button class="btn" data-size="m" data-emphasis="subtle-dark">Minimo</button>

Com ícone

  • Adicione -ico ao final de data-size (data-size="l-ico", data-size="m-ico", data-size="s-ico").
  • Coloque <span class="material-symbols-outlined"> como primeiro filho do botao. O nome do icone e o texto interno do span.
  • Qualquer icone da biblioteca Material Symbols funciona. Consulte em fonts.google.com/icons.
<button class="btn" data-size="m-ico" data-emphasis="subtle">
  <span class="material-symbols-outlined">download</span>
  Baixar
</button>
data-size="l-ico" Icone 20px (1.25em de btn-l). Padding 16/32px, lado esquerdo reduzido para 24px. Gap 8px entre icone e texto.
data-size="m-ico" Icone ~17.5px (1.25em de btn). Padding 12/24px, lado esquerdo 16px. Gap 8px.
data-size="s-ico" Icone 15px (1.25em de btn-s). Padding 8/16px, lado esquerdo 12px. Gap 8px.

Como link

  • Use <a href="..."> no lugar de <button> para acoes que navegam para outra URL.
  • Os atributos data-size e data-emphasis funcionam de forma identica no elemento <a>.
  • Adicione target="_blank" rel="noopener" para links externos.
<a href="/destino" class="btn" data-size="m" data-emphasis="medium-core">
  Ir para destino
</a>

<!-- Link externo -->
<a href="https://..." class="btn" data-size="m" data-emphasis="subtle"
   target="_blank" rel="noopener">
  Abrir site
</a>
Exemplo de link

Como usar

  • Sempre use os tres atributos juntos: class="btn", data-size e data-emphasis.
  • Use no maximo um botao data-emphasis="high" ou data-emphasis="medium-core" por tela — eles representam a acao principal.
  • Para navegacao entre paginas, use <a href="..."> no lugar de <button>: os atributos funcionam identicamente.
  • Adicione -ico ao data-size e um <span class="material-symbols-outlined"> como primeiro filho para versao com icone.
  • Em formularios: botao de submit usa type="submit" e cancelar usa type="button".

Tags interativas para filtragem, categorizacao e selecao. Tres tamanhos (S, M, L), duas cores de fundo (grey e dark) e tres estados: default, hover e active.

Showcase

Estrutura

class="tag" Classe base obrigatoria. Define border-radius 1920px, transicao, flex interno e cor de texto padrao bw-75.
data-color="grey" data-color="dark"
data-color="grey": fundo dn500, para superficies medias. data-color="dark": fundo dn800, para superficies mais escuras.
data-size="l" data-size="m" data-size="s"
L: padding 8/12px, 1rem. M: padding 8/12px, 0.875rem. S: padding 4/8px, 0.75rem. Combine sempre com a classe base e os dois atributos.

Estados

:hover class="is-hover"
Fundo muda para bw-75 (quase branco) e texto para bb (preto). Funciona automaticamente via CSS :hover e pode ser forcado com is-hover para showcase.
class="is-active" Fundo pc500 (roxo brand) e texto bw. Use para indicar o filtro selecionado atualmente. Aplicar e remover via JS no click.
Exemplo de filtro com JS Adicione class="is-active" no click e remova das outras tags do mesmo grupo. A classe e a fonte de verdade, sem estado adicional.

Tamanhos

data-size="l" Padding 8/12px, font 1rem. Para filtros principais e tags de destaque.
data-size="m" Padding 8/12px, font 0.875rem. Padrao para a maioria dos casos.
data-size="s" Padding 4/8px, font 0.75rem. Para filtros em tabelas ou espacos compactos.

Como usar

  • Sempre combine class="tag", data-color e data-size — todos os tres sao obrigatorios.
  • Use data-color="grey" em superficies padrao (dn700/dn600) e data-color="dark" em superficies mais escuras (dn800+).
  • Gerencie o estado ativo via JS: adicione class="is-active" na tag clicada e remova das demais do grupo.
  • Use em elemento interativo: <button> para acoes, <a> para navegacao.
<div class="filtros">
  <button class="tag is-active" data-color="grey" data-size="m" data-filter="todos">Todos</button>
  <button class="tag" data-color="grey" data-size="m" data-filter="design">Design</button>
  <button class="tag" data-color="grey" data-size="m" data-filter="tech">Tech</button>
</div>

<script>
document.querySelectorAll('.filtros .tag').forEach(tag => {
  tag.addEventListener('click', () => {
    document.querySelectorAll('.filtros .tag').forEach(t => t.classList.remove('is-active'));
    tag.classList.add('is-active');
  });
});
</script>

    Dropdown em formularios

    O dropdown nao usa <select> nativo porque os <option> sao renderizados pelo sistema operacional: impossivel estilizar de forma consistente entre Chrome, Firefox e Safari. A solucao e uma estrutura HTML custom com um <input type="hidden"> que carrega o valor para o form e JS minimo para o toggle e a selecao.

    class="dropdown-group" Wrapper com position:relative. Recebe class="is-open" para mostrar a lista e anel pc500 no trigger. Recebe class="is-open-up" quando o JS detecta espaco insuficiente abaixo: a lista abre acima do trigger.
    class="dropdown" Trigger clicavel. Padding 12/16px. class="dropdown-placeholder": texto bw-50. Apos selecionar, troque para class="dropdown-value" (texto bw). Icone expand_more / expand_less no lado direito.
    class="dropdown-options" position:absolute; top:100%; z-index:999 — abre sobre o conteudo. Quando dentro de um container com overflow:hidden (ex.: cards com .wave), o JS detecta o ancestral via getComputedStyle e mede o espaco disponivel dentro dele: tenta abrir para baixo, depois para cima, e como fallback abre para baixo com max-height + scroll. O dropdown nunca ultrapassa os limites do container. Modifiers: class="dropdown-options-separators" (borda bw-10) e class="dropdown-options-detached" (gap 8px + radius + shadow).

    HTML completo para uso em formularios:

    <form>
  <div class="input-group">
    <span class="input-label">Estado</span>
    <div class="dropdown-group">
      <input type="hidden" name="estado" value="">
      <div class="dropdown">
        <span class="dropdown-placeholder">Selecione</span>
        <span class="dropdown-icon material-symbols-outlined">expand_more</span>
      </div>
      <ul class="dropdown-options dropdown-options-detached">
        <li class="dropdown-option" data-value="sc">Santa Catarina</li>
        <li class="dropdown-option" data-value="sp">Sao Paulo</li>

</form>

    JS container-aware — detecta o ancestral overflow:hidden e mede o espaco disponivel dentro dele. Funciona em qualquer contexto (viewport aberto ou dentro de cards com .wave):

    document.querySelectorAll('.dropdown-group').forEach(group => {
  const trigger = group.querySelector('.dropdown');
  const opts    = group.querySelector('.dropdown-options');
  const hidden  = group.querySelector('input[type="hidden"]');
  const label   = trigger.querySelector('.dropdown-placeholder, .dropdown-value');
  const icon    = trigger.querySelector('.dropdown-icon');
  const gap     = 8;

  /* Encontra o ancestral overflow:hidden mais proximo como container de clipping */
  function getClipContainer() {
    let el = group.parentElement;
    while (el && el !== document.body) {
      const s = getComputedStyle(el);
      if (s.overflow === 'hidden' || s.overflowY === 'hidden') return el;
      el = el.parentElement;
    }
    return document.documentElement;
  }

  function openDropdown() {
    const container = getClipContainer();
    const cRect = container.getBoundingClientRect();
    const gRect = group.getBoundingClientRect();

    /* Mede altura sem exibir */
    opts.style.maxHeight  = '';
    opts.style.visibility = 'hidden';
    opts.style.display    = 'block';
    const optH = opts.offsetHeight;
    opts.style.display    = '';
    opts.style.visibility = '';

    const spaceBelow = cRect.bottom - gRect.bottom - gap;
    const spaceAbove = gRect.top - cRect.top - gap;

    if (spaceBelow >= optH) {
      /* Cabe abaixo — sem scroll */
      group.classList.remove('is-open-up');
      opts.style.maxHeight = '';
    } else if (spaceAbove >= optH) {
      /* Cabe acima — sem scroll */
      group.classList.add('is-open-up');
      opts.style.maxHeight = '';
    } else {
      /* Nao cabe em nenhum — abre abaixo com scroll */
      group.classList.remove('is-open-up');
      opts.style.maxHeight = Math.max(spaceBelow, 40) + 'px';
    }
    group.classList.add('is-open');
    if (icon) icon.textContent = 'expand_less';
  }

  function closeDropdown() {
    group.classList.remove('is-open', 'is-open-up');
    opts.style.maxHeight = '';
    if (icon) icon.textContent = 'expand_more';
  }

  trigger.addEventListener('click', e => {
    e.stopPropagation();
    group.classList.contains('is-open') ? closeDropdown() : openDropdown();
  });

  group.querySelectorAll('.dropdown-option').forEach(opt => {
    opt.addEventListener('click', e => {
      e.stopPropagation();
      label.textContent = opt.textContent;
      label.className   = 'dropdown-value';
      if (hidden) hidden.value = opt.dataset.value ?? opt.textContent;
      closeDropdown();
    });
  });

  document.addEventListener('click', closeDropdown);
});

    Estrutura

    class="tooltip" Classe base. Define border-radius 8px, display inline-flex e cor bw. Adicione data-size e data-bg para tamanho e fundo.
    data-size="l" data-size="m" data-size="s"
    L: padding 12/16px, 1rem, max-width 384px. M: padding 8/12px, 0.875rem, max-width 256px. S: padding 4/8px, 0.75rem, max-width 128px.
    data-bg="dn500" data-bg="dn800"
    Fundos solidos. dn500 (Grey) para superficies medias, dn800 (Dark) para superficies mais escuras. Ambos mantem legibilidade com o texto bw padrao.
    data-bg="white-15" data-bg="black-25"
    Fundos glassmorphism com backdrop-filter blur(16px). white-15 para overlays em telas escuras, black-25 para overlays em telas claras. Precisam de elemento semitransparente sob eles para o blur funcionar.

    Tamanhos

    data-size="l" Tooltip Large Padding 12/16px, 1rem, max-width 384px. Para tooltips informativos ou com mais texto.
    data-size="m" Tooltip Medium Padding 8/12px, 0.875rem, max-width 256px. Padrao para a maioria dos casos.
    data-size="s" Tooltip Small Padding 4/8px, 0.75rem, max-width 128px. Para tooltips curtissimos em espacos compactos.

    Posicionamento: data-pos

    • O atributo data-pos indica de que lado o tooltip aparece em relacao ao elemento trigger.
    • 4 valores: data-pos="t" (4px acima, centralizado), data-pos="b" (4px abaixo, centralizado), data-pos="l" (4px a esquerda, centralizado), data-pos="r" (4px a direita, centralizado).
    • O tooltip aparece e some com transicao de opacidade de 0.5s. Use opacity: 0 para ocultar e opacity: 1 para exibir.
    • Posicione via JS usando getBoundingClientRect() do trigger: calcule o lado mais proximo do cursor e aplique o offset de 4px.

    Exemplo interativo: data-pos

    Mova o mouse sobre o botao abaixo. O tooltip aparece no lado mais proximo do cursor a 4px de distancia, centralizado no eixo perpendicular. O data-pos e atualizado automaticamente.

    data-pos="?" 
    <!-- data-pos dinamico via JS -->
<div style="position: relative; display: inline-block;">
  <button class="btn" data-size="m" data-emphasis="subtle"
          onmouseenter="showTip(this, event)">
    Botao
  </button>
  <span class="tooltip" data-size="m" data-bg="dn800" id="meu-tip"
        style="position:absolute;pointer-events:none;display:none;">
    Tooltip
  </span>
</div>

<script>
function showTip(trigger, e) {
  const tip  = document.getElementById('meu-tip');
  const rect = trigger.getBoundingClientRect();
  // Calcula posicao relativa e define data-pos
  const dy = e.clientY - (rect.top + rect.height / 2);
  tip.dataset.pos = dy < 0 ? 't' : 'b';
  // Posiciona via CSS absolute — ajuste left/top conforme necessario
  tip.style.display = 'inline-flex';
}
</script>

    Implementacao CSS obrigatoria

    Todo layout que use o grid DS deve ser implementado com repeat(M, 1fr) + gap: G no container e grid-column: span N nos filhos. Cada 1fr equivale a exatamente uma coluna DS; cada gap equivale a exatamente um gutter DS. Esta e a unica forma pixel-perfect de replicar o grid em CSS.

    Por que Nfr Mfr e proibido

    Com grid-template-columns: 3fr 5fr o CSS distribui o espaco livre apos subtrair 1 gutter, nao 7. Para um grid de 8 colunas com gutter de 32px, isso produz um nav 8px mais largo que o esperado, e o erro e constante em qualquer largura de viewport. fr sem repeat(M, 1fr) e proibido em todos os layouts do projeto.

    Formula do desvio: Nfr = N × C/M - G × 1/M ; DS = N × C/M - G × (M-1)/M. Diferenca = G × (M-2)/M. Para M=8, G=32: 32 × 6/8 = 24px de erro teorico, mas como a coluna de 3 nao e o unico filho o CSS distribui igualmente e o desvio observado e 8px = G/4.

    Padrao de codigo 
    /* Container — usa repeat(M, 1fr) para cada breakpoint */
.layout {
    display: grid;
    grid-template-columns: repeat(10, 1fr);  /* >= 1440px: 10 colunas */
    gap: 32px;
}

/* Filhos usam span N — sem largura fixa, sem fr parcial */
.sidebar { grid-column: span 3; }
.main    { grid-column: span 7; }

@media (max-width: 1439px) {
    .layout  { grid-template-columns: repeat(8, 1fr); }
    /* sidebar permanece span 3; main passa para span 5 */
    .main    { grid-column: span 5; }
}

@media (max-width: 864px) {
    .layout  { grid-template-columns: repeat(6, 1fr); gap: 24px; }
    .sidebar { grid-column: span 3; }
    .main    { grid-column: span 3; }
}

@media (max-width: 576px) {
    .layout  { grid-template-columns: repeat(4, 1fr); gap: 16px; }
    .sidebar { grid-column: span 4; }   /* ou display:none conforme o layout */
    .main    { grid-column: span 4; }
}
    Alternativa com calc() — somente se repeat nao for possivel

    Se por algum motivo tecnico repeat(M, 1fr) nao puder ser usado, a largura exata de N colunas em um grid de M colunas com gutter G e:

    /* Largura exata de N colunas DS num grid M com gutter G */
width: calc(N/M * 100% - G * (M - N) / M);

/* Exemplo: 3 colunas em grid de 8, gutter 32px */
width: calc(37.5% - 20px);   /* 3/8 * 100% - 32 * 5/8 */

    Esta formula e um fallback de ultima instancia. O padrao obrigatorio e sempre repeat(M, 1fr) + span N.
