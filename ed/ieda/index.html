O projeto

Vamos construir um radar que acompanha as licitações do governo enquanto você dorme

Todo dia, o Portal Nacional de Contratações Públicas (PNCP) publica mais licitações do que qualquer equipe consegue ler. São editais longos, dados espalhados e oportunidades que passam sem ninguém ver.

  • Coleta

    Coleta as licitações do PNCP automaticamente, todos os dias

  • Organiza

    Organiza os dados em camadas medalhão no Supabase

  • Lê

    Lê os editais e responde perguntas.

  • Mostra

    Mostra tudo num painel no Power BI

  • Avisa

    Avisa no Telegram quando aparece algo novo

Na imersão, você vai construir o Radar Inteligente de Licitações Públicas, um projeto real, com dados reais.
