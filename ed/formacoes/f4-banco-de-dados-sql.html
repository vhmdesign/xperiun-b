Preciso saber programar pra fazer SQL? add

Não. SQL não é linguagem de programação no sentido tradicional, é linguagem de consulta. A formação inclui o curso de Lógica de Programação como bônus pra quem quer fundamento, mas você consegue rodar SQL útil sem virar programador.

A formação serve pra quem nunca abriu um banco de dados? add

Serve. O minicurso bônus (2h) entrega consulta funcional pra quem está zerado, e o curso principal parte da estrutura básica antes de ir pra avançado. Quem nunca abriu banco e quem já mexeu rodam confortável aqui.

Quanto tempo leva pra terminar? add

Aluno que dedica 1 hora por dia (5h por semana) termina em 11 a 14 semanas. Carga total ~57h, formação cirúrgica e focada. Se você priorizar SQL e Raciocínio Lógico antes do Data Warehouse, faz em 8 semanas.

Posso começar por essa ou tenho que fazer outra antes? add

Pode começar por essa direto. SQL é independente das outras formações, não pressupõe Power BI nem Python. Inclusive funciona como porta de entrada alternativa pra quem prefere caminho técnico antes de ferramenta visual.

Os exemplos do curso são em qual banco (MySQL, PostgreSQL, SQL Server)? add

A formação cobre os fundamentos de SQL que valem pros 3 principais bancos do mercado (MySQL, PostgreSQL, SQL Server). A sintaxe é praticamente idêntica em ~85% dos casos, com pequenas variações nos comandos avançados, que o curso aponta explicitamente.
